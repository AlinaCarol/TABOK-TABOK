# Crossy Road Base (Godot 4 + C#)

1. Install Godot 4.3+ (the **.NET** build) and the .NET 6+ SDK.
2. Open Godot -> Import -> select `project.godot`.
3. Press Build (hammer icon, top right), then Play (F5).

Controls: WASD / Arrow keys to hop. R / Space to restart after dying.

If you use Godot 4.4+, change `net6.0` to `net8.0` and the SDK version in `CrossyRoadBase.csproj`.
